# REEVO Email Signature Maker

Interactive email signature generator and formatter for REEVO team members.

## Features
- **Live Preview:** Instant real-time rendering.
- **Proportional Scaling:** Resize signature from 70% to 115% with optimized mobile/compact presets.
- **Position Sliders:** Horizontal and vertical alignment fine-tuning.
- **Font:** Clean Google Montserrat font styling with standard email-safe fallbacks.
- **Optional Slogan:** Bottom motto line support.
- **One-Click Export:** Rich-text clipboard copy for Gmail, standalone `.html` download, and raw HTML code copying.

## How to Use
1. Open `index.html` in any browser (or view via GitHub Pages).
2. Enter your name, job title, phone number, and email.
3. Click **Copy Signature for Gmail**.
4. In Gmail, navigate to **Settings > See all settings > General > Signature**, paste (`Ctrl + V`), and save changes.
